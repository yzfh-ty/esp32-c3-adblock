🛡️ C3 AdBlocker

一台 $2 的 ESP32-C3 全网络 DNS 广告拦截器——141,000+ 域名，无需 PSRAM。直接在这里烧录，无需工具链。

把你的 ESP32-C3 插入这台电脑，然后：

你的浏览器无法烧录——请在桌面上使用 Chrome 或 Edge。 请通过 HTTPS 或本机 localhost 地址打开此页面，才能使用串口烧录。

正在加载烧录组件…

请在项目目录打开 PowerShell，运行：

python -m http.server 8000 --bind 127.0.0.1 --directory docs

然后打开 本机烧录页面，使用期间保持终端打开。结束后在终端按 Ctrl+C 关闭服务。

Chrome / Edge · 桌面版 约 30 秒 已内置拦截列表
会发生什么
  1. 点击 连接并安装，然后选择你的 ESP32-C3 的串口。
  2. 它会烧录固件 + 一个 14.1 万域名的拦截列表（约 30 秒）。
  3. 重启后，它会创建一个名为 C3-AdBlock-XXXX 的 WiFi 网络——用手机连上它，选择你的 WiFi，输入密码。
  4. 把它设为你路由器的备用 DNS（或逐设备设置），广告就会被全网拦截。仪表盘在 c3adblock.local。

这个固件没有内置任何 WiFi 凭据——你在设备上进行私密设置。
